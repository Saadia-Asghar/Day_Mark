MAIN PRODUCT GOAL

Turn Daymark into a product users want to return to daily.

Daymark should have three layers:

1. PRIVATE MEMORY
   Save life for yourself.

2. RELATIONSHIP MEMORY

==================================================
PART 1: INTRODUCE “DAYLINK” STREAKS
==================================================

Feature name:

Daylink ✨

Alternative UI label:

Memory Streak

Daylink measures how many consecutive days two connected Daymark users have shared or saved a meaningful moment together.

This should NOT be based on generic chat messages.

A day counts when at least one qualifying shared action happens between two connected users.

QUALIFYING ACTIONS

Examples:

- shared photo memory
- shared written memory
- shared voice memory, when implemented
- one user sends the other a Memory Drop
- both are tagged in a new shared memory
- one user responds to a Daily Prompt together
- one user sends a Daymark moment and the recipient opens/reacts to it

DO NOT count:

- opening the app
- liking something repeatedly
- empty messages
- spam interactions

The streak should reward meaningful connection.

PART 3: STREAK LOGIC
==================================================

At most one streak day can be earned per relationship per calendar day.

Example:

Day 1:
Saadia and Sarah save a memory together.

Daylink:
1 ✨

Next day:
one of them shares a memory and the other opens it.

Daylink:
2 ✨

If another qualifying action happens that same day:

remain:
2 ✨

Do not increment multiple times per day.
