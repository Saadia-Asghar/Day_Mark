Audit every Daymark mascot/character asset currently used in the frontend.

CURRENT PROBLEM

Characters such as Marky are being displayed as rectangular image assets with
visible beige/white backgrounds.

This makes the characters look pasted into the interface rather than part of
the Daymark world.

I want ALL Daymark characters to:

- have transparent backgrounds
- appear as standalone mascot figures
- blend naturally into the UI
- have subtle animation
- react differently depending on the screen/state
- remain visually consistent throughout the app

DO NOT redesign the characters themselves unless required.

9. FRAMER MOTION
==================================================

Use Framer Motion for UI character animation.

Create reusable animation presets.

Example:

idleFloat:

animate:
{
  y: [0, -4, 0],
  rotate: [0, 1, 0]
}

transition:
{
  duration: 3.5,
  repeat: Infinity,
  ease: "easeInOut"
}

Wave:

rotate arm/avatar gently once when screen opens.

Celebrate:

scale:
1 → 1.08 → 1

y:
0 → -8 → 0

Then stop.

Do not loop celebration forever.

13. DEPTH
==================================================

Because backgrounds are transparent, create depth using CSS rather than baked
image backgrounds.

Use subtle:

filter: drop-shadow()

Example:

drop-shadow(0 8px 12px rgba(50, 32, 96, 0.15))

Do not use strong rectangular box shadows.

The shadow should follow the mascot silhouette.
