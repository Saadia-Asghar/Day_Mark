TASK 3: PHYSICAL GIFT-CLOSING ANIMATION
==================================================

Build one reusable physical gift animation component.

Suggested name:

PhysicalGiftAnimation

Reuse it in:

- Wrap a Memory
- Create Future Gift
- Gift Detail opening where appropriate

Closing sequence:

1. Memory photo moves into the open box
2. Box lid lowers
3. Horizontal ribbon wraps around it
4. Vertical ribbon wraps around it
5. Bow forms
6. Gift tag attaches
7. Marky catches or presents the finished gift
8. Success message appears

Duration:

0.9 to 1.4 seconds

Use Framer Motion.

Do not use excessive confetti.

Use deterministic decorative particles.

Do not call Math.random() during render.

Respect prefers-reduced-motion.

Reduced-motion behavior:

- skip complex movement
- use one soft fade and scale
- immediately show success state

The animation must not block navigation or trap the user.
