==================================================
PART 47: GLOBAL MEMORY GLOBE
==================================================

Add a new optional discovery feature called:

Memory Globe 🌍

Alternative name:

Around the World

The idea:

Users can explicitly choose to publish selected memories to a global Daymark map.

Only memories that users manually approve for public discovery should appear.

Private memories must NEVER appear automatically.

The Globe should let people discover small everyday moments from around the world.

Examples:

Karachi
“Chai after class with my best friend.”

Tokyo
“First cherry blossoms of the season.”

Istanbul
“Breakfast with my grandmother.”

Hunza
“Sunrise before everyone woke up.”

The focus should be ordinary human moments, not influencer content.

==================================================
GLOBAL MEMORY PRIVACY MODEL
==================================================

Add explicit publication state to memories.

Recommended fields:

visibility

private
connections
public_globe

Add optional public sharing fields:

- globePublishedAt
- globeLocationLabel
- globeLatitude
- globeLongitude
- globePrecision
- globeCaption
- globeAnonymous
- globeShowUsername
- globeShowDate
- globeShowLocation
- globeShowPhoto

DEFAULT:

private

Never publish anything to the Globe without direct user action.

==================================================
LOCATION PRIVACY
==================================================

Exact coordinates must NOT be public by default.

Use approximate location.

Options:

City
Region
Country

Default:

City-level or coarser

For example:

Islamabad, Pakistan

rather than:

exact hostel building coordinates

If user enables map sharing, explain clearly:

“Your exact location stays private. Daymark will only show the approximate area you choose.”

Do not expose home addresses or precise GPS coordinates.

==================================================
GLOBAL GLOBE SCREEN
==================================================

Create route:

/globe

Make this one of Daymark's most visually impressive screens.

Do NOT add it as another bottom navigation item.

Access it from Home through:

Around the World 🌍

or

Memory Globe

The interface should show an interactive globe or world map.

Use soft Daymark visual styling:

cream
lavender
purple
small glowing memory points

Each public memory should appear as a small glowing pin or gift/star point.

Do not use aggressive heat maps.

==================================================

==================================================

Users can:

- rotate globe
- zoom
- tap a glowing point
- open a small memory card
- move between nearby memories

Memory preview shows:

photo
short caption

small Daymark category tag

CTA:

Open Moment

Do not expose private profile data.

==================================================
DISCOVERY PHILOSOPHY
==================================================

Memory Globe should NOT become:

Instagram Explore
TikTok feed
influencer discovery
engagement leaderboard

Avoid:

likes count
followers
view count
trending creators
most popular memories

Daymark should celebrate ordinary life.

Recommended language:

Small moments from everywhere.

==================================================
LIGHTWEIGHT REACTIONS
==================================================

For public Globe memories, optionally allow only simple reactions.

Examples:

💜
✨
🥹

Do NOT show public reaction totals prominently.

A user may see that someone reacted to their public memory through notifications.

Do not create comment threads in the first version.

==================================================
PUBLIC MEMORY REPORTING
==================================================

Add:

Report Memory

Reasons:

- personal information
- harassment
- inappropriate content
- spam
- unsafe location disclosure
- other

Reported memories should be flagged for review.

Also allow users to:

Remove from Globe

at any time.

Removal should immediately make it unavailable through Globe queries.

==================================================
BLOCKED USERS
==================================================

If User A blocks User B:

User B should not see User A’s public Globe memories while authenticated.

Likewise:

User A should not see User B’s memories.

Where technically reasonable, enforce blocking in Globe discovery queries.

==================================================
GLOBE API
==================================================

Create endpoints such as:

GET /api/globe/memories

Query parameters:

- bounds
- since
- category
- limit
- cursor

POST /api/memories/:id/publish-globe

PATCH /api/memories/:id/globe-settings

DELETE /api/memories/:id/globe

Do not return full private memory objects.

Create a dedicated public DTO containing only allowed fields.

Example:

{
  publicId,
  caption,
  photoUrl,
  category,
  locationLabel,
  approximateLatitude,
  approximateLongitude,
  displayName,
  anonymous,
  date
}

Never return:

owner email
internal user id
private story
private people
exact GPS
private media
scheduled content

==================================================
GLOBE + DAYLINK SEPARATION
==================================================

Public Globe interactions must NOT count toward Daylink streaks.

Daylink is for real connected relationships.

Global discovery is separate.

Do not let random public reactions maintain streaks.
