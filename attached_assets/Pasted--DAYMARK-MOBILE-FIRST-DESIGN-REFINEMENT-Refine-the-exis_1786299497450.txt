# DAYMARK — MOBILE-FIRST DESIGN REFINEMENT

Refine the existing Daymark design. DO NOT restart the project and DO NOT replace the core concept.

The current gift-box memory concept is correct, but the visual system needs to become significantly more distinctive, polished, youthful, vibrant, and MOBILE-FIRST.

From this point onward, prioritize the MOBILE APP.

Do not spend time expanding the desktop landing page yet.

## 1. KEEP THESE EXISTING IDEAS

Keep:

* Daymark name
* Memory = Gift concept
* Purple gift-box mascot
* Warm cream background
* Purple as the main brand color
* Pink, yellow, lavender, mint and blue supporting colors
* Gift boxes
* ribbons
* photographs
* handwritten notes
* stars
* hearts
* flowers
* emotional memory storytelling
* tagline concept: "Keep the little gifts life gives you."

Do NOT remove the gift metaphor.

Instead, make it much more deeply integrated into the product.
