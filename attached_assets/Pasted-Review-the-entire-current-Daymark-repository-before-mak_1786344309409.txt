MAIN GOAL

Make Daymark feel like a polished consumer product people WANT to return to
because something meaningful is waiting for them.

Do NOT rely on manipulative engagement patterns.

The daily value loop should be:

REMEMBER
Something from my past comes back.

KEEP
I save one little thing from today.

CONNECT
I continue a meaningful shared story with someone.

DISCOVER
I see an ordinary moment someone chose to share from somewhere else.

ANTICIPATE
Something is waiting for me in the future.

==================================================
4. DAYLINK QUALIFYING ACTIONS
==================================================

A relationship can earn AT MOST one Daylink day per calendar day.

Qualifying:

- create a shared memory
- send a Memory Drop and recipient opens/reacts
- answer Today’s Little Question together
- add content to a shared memory
- share another meaningful Daymark moment

Do NOT count:

- opening app
- profile views
- searching
- repeated reactions
- Globe activity
- notification opens

Use database-level protection against double increments.
